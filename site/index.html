Self-hosted · Open source · Human-approved actions

A more thoughtful way to review your mail.

Personal Digital Assistant is a self-hosted email briefing and review assistant. It brings unread Gmail and Microsoft mail into concise daily summaries and keeps mailbox changes behind explicit approval.

View the project Read the privacy policy

Runs under your control

You operate the assistant and choose where it runs, which accounts it can access, and which language model it uses.

Read-only by default for reports

Daily collection does not download attachments. Optional mailbox organization is separate and requires an explicit approval.

Private delivery

The reference setup sends reports and approval requests to the configured Discord direct message, not a public server channel.

This is software you install and operate yourself, not a hosted mailbox service. Review the Privacy Policy and Terms of Service before configuring an account.
