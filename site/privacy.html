Privacy Policy

Personal Digital Assistant (“PDA”) is open-source software that you install and operate in an environment you control. The project maintainer does not operate a hosted mailbox service and does not receive mailbox data through this website. The person or organization operating an installation controls its configuration and data.

Information the software processes

When configured and authorized by its operator, PDA can process mail from the selected Gmail and Microsoft accounts. This can include sender and recipient information made available to the integration, subject, message date, unread status, message identifiers, message text needed to prepare summaries, and attachment names. Attachment contents are not downloaded by the reference implementation.

The daily report selects unread messages from the previous calendar day in the configured time zone. A separate new-mail review can process messages received after its configured starting cursor. The assistant may create local summaries and proposed categories or actions. The reference workflow does not intentionally store complete message bodies in its state database; local report output, message metadata, recommendations, and audit records may remain in the operator’s data directory.

Where information goes

  • Operator-controlled storage: OAuth credentials, message identifiers, workflow state, recommendations, and audit information are stored in the persistent data directory chosen by the operator. Credential files are restricted by filesystem permissions. The operator is responsible for device security, backups, and deletion.
  • Language model: Mail text is sent to the model endpoint configured by the operator to produce summaries or classifications. The documented reference deployment uses a local LM Studio model. If an operator configures a hosted model instead, the relevant message content is sent to that provider and its terms and privacy practices apply.
  • Discord: The reference deployment sends rendered reports and separate approval notifications to the operator’s configured Discord direct message. Discord receives and retains those messages under Discord’s own policies. Do not configure a public channel for private mail content.
  • Mail providers: Gmail and Microsoft receive OAuth/API requests needed to read the selected mail and, only when enabled and explicitly approved, perform supported mailbox actions.
  • Website hosting: These informational pages are hosted by GitHub Pages. GitHub may process technical request data under its own privacy statement.

The project maintainer does not sell mailbox information or collect it for advertising. The static project website does not include analytics or advertising scripts.

Permissions and mailbox actions

Reporting uses Gmail read-only and Microsoft delegated mail-read permissions. Separate management credentials can enable supported organization actions. In the reference deployment, a mailbox mutation requires an authorized, explicit approval in Discord. The software may mark a successfully reported message read, apply a label or category, archive a message, move it to spam/Junk, or perform an allowlisted HTTPS one-click unsubscribe after approval. Deletion, sending mail, and automatic mailto unsubscribe are not enabled. Operators should review the installed version and configuration because this software can be modified.

Retention and deletion

PDA does not provide a central account or a maintainer-operated retention service. Data can remain in the operator’s persistent assistant directory, local reports, audit records, Discord history, and any backups until the operator deletes it. Approval requests in the reference configuration remain open until decided or closed. The operator can stop the assistant, remove its local data and backups, delete Discord messages, and revoke the OAuth grant in Google or Microsoft. Deleting local files does not delete copies held by those providers or Discord.

Security

The reference deployment keeps credentials outside the source repository, restricts credential file permissions, and supports encrypted backups. No software can guarantee absolute security. Operators should keep the host and dependencies updated, protect the device and backup password, limit OAuth scopes, and revoke exposed credentials promptly. Do not send email content, tokens, or account identifiers in public issues.

Children and changes

PDA is intended for personal productivity use by adults and is not designed for children. This policy may be updated when the software’s data practices change. The date above identifies the latest revision of this page.
